### 📄 [모듈 3 상세 명세서] 뚝딱 레시피 커뮤니티 (Recipe Engine)
#### 1. 개요 및 시스템 정책
*   **목적** : 1인 가구 및 자취생이 손쉽게 레시피를 공유·탐색하고, 내 냉장고 식재료 매칭 점수 및 양념류가 제외된 실용적 FIFO 재료 차감 기능 제공.
*   **주요 제약사항** :
*  레시피 등록 시 사용되는 재료는  **반드시 ingredient_master 테이블에 사전 등록된 표준 식재료만 선택 가능**  (자유 텍스트 입력 불가).
*   **주재료(Main)와 부재료(Sub) 구분 필수** : 주재료 미보유 시 '내 냉장고 매칭 모드' 노출 제외.
*   **양념/소스/조미료 카테고리** : 냉장고 수량 차감 대상에서  **자동 제외** .
*   **커뮤니티 클립화** : 후기 작성/댓글/신고 기능을 과감히 제거하여 UX 복잡도를 최저 수준으로 유지.
*  회원 탈퇴 시 레시피는 익명화(user_id = NULL)되어 커뮤니티 자산으로 보존되며, 작성자가 NULL인 익명 레시피는 모든 유저의 수정/삭제 요청이 완전 차단(403 Forbidden)됨.

#### 2. 세부 기능 요구사항 (Functional Requirements)
##### 2.1. 레시피 작성 및 수정 (Create & Update)
*   **REC-01-1 [레시피 기본 정보 입력]** :
*  레시피 제목 (필수, 최대 50자), 한 줄 소개 (선택, 최대 100자), 대표 이미지 (선택, Supabase Storage).
*  기준 인분 (필수, 기본 1인분), 조리 시간 (필수, N분), 난이도 (필수: 쉬움/보통/조금복잡).
*  카테고리 (필수):  **8개 고정 카테고리**  (국/찌개/탕, 메인반찬, 밑반찬, 한그릇/밥, 면/만두, 간식/디저트, 안주/야식, 기타).
*   **REC-01-2 [표준 식재료 바인딩 및 대체/생략 옵션]** :
*   **식재료 선택 UI** : Searchable Select(Combobox)로 ingredient_master 조회 후 선택.
*   **재료 구분 (Type)** : MAIN (주재료) vs SUB (부재료) (작성 가이드 툴팁 상시 노출).
*   **부재료 전용 부가 설정** : 대체 가능 표준 재료 선택 + 생략 가능 여부 체크(is_optional).
*   **필요 수량 및 단위** : 수량(숫자, inputmode="numeric") 및 단위(개, g, ml, 큰술 등) 입력.
*   **REC-01-3 [조리 순서 (Step) 작성]** :
*  Step별 순서, 조리 설명 텍스트(필수), 이미지 첨부(선택), 순서 변경 및 추가/삭제.
*   **REC-01-4 [수정 권한 검증]** :
*  본인이 작성한 레시피만 수정/삭제 가능.
*   **REC-01-5 [자추(본인 레시피 좋아요/요리완료) 허용 및 소셜 알림 처리 정책]** :
*  본인이 작성한 레시피에 대해 직접 [좋아요] 및 [요리완료]를 실행하는 행위(자추)는 전면 허용함.
*  단, 본인의 행위로 인한 알림 도배 방지 및 피드백 순환을 위해 자기 자신의 액션에 대해서는 피호출자 소셜 알림을 생성하지 않음 (`authorId != actorId` 조건으로 알림 발송 스킵).

##### 2.2. 레시피 탐색 및 상세 조회 (Read)
*   **REC-02-1 [목록 보기 모드 분리 (전체 보기 vs 🟢 내 냉장고 뚝딱 매칭)]** :
*   **기본 모드 (전체 보기)** :
*  최신순/인기순/조리시간 단축순 정렬, 8개 카테고리 필터, 제목+식재료명 키워드 검색.
*  내 냉장고 기반 매칭 점수 배지(예: 매칭률 85%)를 카드 상단에 연하게 노출 (부하 방지를 위해 상세 배지 미출력).
*   **토글 모드 (🟢 내 냉장고 뚝딱 매칭)** :
*  상단 토글 버튼 클릭 시 내 냉장고 재료 기반으로 즉시 조리 가능한 레시피만 필터링. (8개 레시피 카테고리 필터와 조합 가능)
*   **최소 매칭 조건** :  **주재료 최소 1개 이상 필수 보유**  (주재료가 없으면 매칭 목록에서 제외).
*   **소비기한 임박 가산점** : 소비기한 임박(D-0 ~ D-3) 재료가 들어간 레시피에 가산점 부여 (주재료 임박 시 더 큰 가산점 부여하여 '냉털 요리' 최상단 배치).
*   **REC-02-2 [레시피 상세 페이지]** :
*   **기본 정보** : 작성자 닉네임(닉네임(#태그)), 작성일, 난이도, 조리시간, 기준 인분.
*   **인분(Portion) 변환 계산기** : 인분 수 조절 시 모든 필요 재료 수량 비례 자동 재계산.
*   **상세 재료 보유 현황 배지** :
*  상세 페이지 진입 시에만 내 냉장고 데이터와 연동하여 [보유중 🟢], [부족함 🔴], [대체가능 🟡] 배지 표기.
*  양념/소스 카테고리 재료: [양념류 ⚪] 배지로 표기하여 차감 제외 대상임을 명시.
*   **조리 순서** : Step별 이미지 및 설명 순차 노출.

##### 2.3. 요리 실행 및 2차 확인 차감 (Execute & Confirm)
*   **REC-03-1 [2차 확인 차감 팝업 (Confirm Modal)]** :
*  [이 레시피로 요리하기] 클릭 시 실수 방지용 confirmation 팝업(AlertDialog) 노출.
*   **차감 대상 자동 필터링** : 양념/소스 카테고리 재료는 차감 목록에서  **자동 제외**  및 [양념 - 수량차감 제외] 배지 시각화.
*   **수량 미세 조절 UX 시각화** :
*  팝업 상단에  **인분 조절 버튼(- / +)**  제공 ➔ 클릭 시 차감 수량 비례 자동 재계산.
*  숫자가 표기된 박스에  **연한 연필 아이콘(✏️)과 안내 문구** ( *"수량을 터치하여 직접 변경할 수 있어요"* )를 제공하여 유저 수정 가능성 명시.
*   **옵션 제공 (2-Way 분기)** :
*   **[확인 및 냉장고 차감]** :
  - **원본/대체재료 혼합 차감 금지 정책**: 요리의 고유한 맛 보존을 위해 원본 재료와 대체 재료를 하나의 요리에서 혼합 차감하지 않음. 원본 재료를 최우선 FIFO 차감하며, 보유 수량이 필요 수량보다 적을 경우 보유분만 전량 차감(Partial Deduction)하고 부족분을 대체 재료로 섞어 차감하지 않음.
  - **보유 수량 부족 시 유연한 전량 차감**: 필요 수량보다 보유 수량이 적어도 에러를 던지지 않고 보유 수량 전량(Partial) 차감 후 차감 내역을 응답으로 반환.
  - **카운터 원자적 업데이트**: 레시피 요리 완료 수(`cooked_count`) 및 좋아요 수(`like_count`)는 DB SQL 레벨에서 원자적(Atomic) `+1` 연산으로 업데이트.
*   **[차감 없이 요리 완료만 기록]** : 냉장고 재료 차감 없이 요리 완료 카운트만 +1 기록.
