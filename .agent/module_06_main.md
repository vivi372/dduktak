### 📄 [모듈 6 상세 명세서] 메인 화면 (Main Home)
#### 1. 개요
*   **목적** : 유저가 앱에 들어왔을 때 내 냉장고 상태를 즉시 확인하고, 오늘 해먹을 수 있는 맞춤 요리와 커뮤니티 인기 레시피를 손쉽게 탐색할 수 있도록 핵심 기능 및 데이터 연결.
*   **빈 상태 처리 (Empty State Policy)** : 신규 유저 또는 등록된 재료가 0개일 때, 비어 있는 화면으로 인한 이탈을 방지하기 위해 직관적인 재료 등록 안내 카드 및 CTA(Action) 버튼 노출.

--------------------------------------------------------------------------------

#### 2. 메인 화면 구성 및 기능 요구사항
##### 2.1. 내 냉장고 브리핑 영역
*   **정상 상태 (재료 1개 이상 보유 시)** :
*  보관 중인 전체 재료 수
*  소비기한 임박 재료 수 (D-3 이내) 및 만료 재료 수
*  클릭 시 내 냉장고 탭으로 이동.
*   **빈 상태 (재료 0개 또는 비로그인 시)** :
*   *"아직 냉장고에 등록된 재료가 없어요!"*  안내 문구 노출.
*   **[+ 첫 재료 등록하기]**  강조 CTA 버튼을 크게 배치하여 내 재료 관리소 탭 또는 재료 등록 팝업으로 즉시 유도.

--------------------------------------------------------------------------------

##### 2.2. 스마트 매칭 레시피 영역 (오늘 뭐 먹지?)
*   **노출 형태** :  **가로 스크롤 (Horizontal Carousel / 좌우 슬라이드)**
*  하단 인기 레시피 리스트(세로)와의 시각적 구분을 위해 좌우 탐색형 카드로 배치.
*   **정상 상태 (재료 1개 이상 보유 시)** :
*  내 냉장고 재료 기반 추천 레시피 (상위 3~5개)
*  레시피 제목, 대표 이미지, 조리시간, 난이도
*  매칭 점수(%) 및 임박 재료 포함 여부 표시
*   **빈 상태 (재료 0개 또는 비로그인 시)** :
*   *"냉장고에 재료를 등록하고 맞춤 레시피를 추천받아보세요!"*  가이드 카드 노출.
*  카드 클릭 시 재료 등록 화면으로 연결.

--------------------------------------------------------------------------------

##### 2.3. 재료 퀵 등록 버튼 영역
*   **기능** :
*  직접 입력 등록 팝업 호출
*  영수증 스캔 카메라 호출
*  바코드 스캔 카메라 호출

--------------------------------------------------------------------------------

##### 2.4. 커뮤니티 인기 레시피 영역 (지금 인기있는 뚝딱 요리)
*   **노출 형태** :  **세로 리스트 (Vertical List / 위아래 스크롤)**
*   **노출 정보** :
*  현재 커뮤니티에서 가장 인기 있는 뚝딱 레시피 목록 (상위 N개)
*  레시피 제목, 대표 이미지, 조리시간, 난이도, 좋아요/요리완료 수
*   **기능** :
*  카드 클릭 시 해당 레시피 상세 페이지로 이동.
*  영역 상단  **[더보기 ➔]**  클릭 시 전체 레시피 목록(레시피 커뮤니티 탭)으로 이동.
