     - 6대 API 엔드포인트 함수 구현:
       - `getNotifications(page, size)`: `GET /api/v1/notifications`
       - `markAsRead(notificationId)`: `PATCH /api/v1/notifications/{id}/read`
       - `markAllAsRead()`: `PATCH /api/v1/notifications/read-all`
       - `deleteNotification(notificationId)`: `DELETE /api/v1/notifications/{id}`
       - `deleteAllNotifications()`: `DELETE /api/v1/notifications/all`

     - 통신 단위 테스트 6건 작성 및 통과 (`notificationApi.test.ts`).
  3. **React Query 커스텀 훅군 격리 (`src/hooks/useNotification.ts`)**:
     - `useNotifications(page, size)`: `useAuthStore`의 `isAuthenticated`와 연동하여 비로그인 시 불필요한 네트워크 호출 차단 및 안전한 기본 객체(`unreadCount: 0, hasUnread: false`) 반환.
     - `useMarkNotificationRead()`, `useMarkAllNotificationsRead()`, `useDeleteNotification()`, `useDeleteAllNotifications()`, `useUpdateNotificationSettings()`: 실행 즉시 `['notifications']` 쿼리 캐시를 무효화하여 헤더 뱃지 및 목록 화면을 원자적으로 동기화.
     - 훅 단위 테스트 7건 작성 및 통과 (`useNotification.test.tsx`).
  4. **상단 헤더 Red Dot 뱃지 실시간 연동 (`Header.tsx`)**:
     - 기존 더미 스토어 제거 ➔ `useNotifications()` 훅의 `hasUnread` 및 `unreadCount`를 `header-red-dot` 뱃지에 실시간 바인딩.
     - `Header.test.tsx` 5건 단위 테스트 통과 (미읽음 알림 존재 시 뱃지 노출, 미존재 시 미노출).
  5. **알림 센터 화면 & 404 Fallback 방어 (`NotificationPage.tsx`, `NotificationCard.tsx`)**:
     - 알림 목록 고속 렌더링, 로딩 스피너, EmptyState, 단일 읽음/삭제 및 일괄 읽음/삭제 액션 실연동.
     - **삭제된 콘텐츠 404 Fallback 처리**: 레시피 관련 알림 카드 클릭 시 `getRecipeDetail(targetId)`를 사전 검증하여, 레시피가 이미 삭제되었거나 404 에러(`RECIPE_WARN_NOT_FOUND`) 발생 시 Sonner Toast로 *"삭제되었거나 더 이상 존재하지 않는 콘텐츠입니다"* 경고를 노출하고 알림 센터 화면을 안전하게 유지.
     - `NotificationPage.test.tsx` 6건 단위 테스트 통과.
  6. **마이페이지 알림 통합 설정 연동 (`MyPage.tsx`)**:
     - 소비기한 알림 토글, 소셜 알림 토글, 야간 방해금지 시간 설정 시 `useUpdateNotificationSettings` 뮤테이션을 통해 백엔드 `PATCH /api/v1/notifications/settings` 단일 통합 API 호출 및 낙관적 업데이트 적용.
     - `MyPage.test.tsx` 9건 단위 테스트 통과.
  7. **단위 테스트 & 프로덕션 빌드 무결점 검증**:
