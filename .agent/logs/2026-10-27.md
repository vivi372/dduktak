## 💬 Command 01. 메인 홈 추천 작성자 정합성 수정 및 화면 전환 깜빡임 최적화

### 1. 작업 목적 및 상세 내역
1. **메인 홈 추천 레시피 작성자 정보 실제 데이터 연동 (이슈 1)**:
   - **원인**: `frontend/src/pages/HomePage.tsx`의 `topRecipeSummary` 객체에 `authorNickname: '뚝딱 셰프'`, `authorTag: '1024'`가 임의로 하드코딩되어 있었으며, 백엔드 `BriefingTopRecipeDto`에 작성자 정보 필드가 누락되어 있었음.
   - **백엔드 수정**:
     - `BriefingTopRecipeDto.java`: `authorNickname`, `authorTag` 필드 추가.
     - `HomeService.java`: `resolveAuthorInfo(recipeId)` 헬퍼를 추가하여 최고 매칭 레시피 및 인기 레시피 폴백 시 `profileRepository`에서 실제 회원의 닉네임과 userTag를 조회하여 세팅 (탈퇴 회원/null인 경우 '관리자', null 세팅).
   - **프론트엔드 수정**:
     - `frontend/src/types/home.ts`: `BriefingTopRecipe` 인터페이스에 `authorNickname?: string`, `authorTag?: string` 추가.
     - `frontend/src/types/recipe.ts`: `RecipeSummary` 인터페이스의 `authorNickname`과 `authorTag`를 optional/nullable로 변경하여 익명/탈퇴 회원 지원.
     - `frontend/src/pages/HomePage.tsx`: 하드코딩되었던 `'뚝딱 셰프'`, `'1024'` 제거하고 `briefing.topRecipe.authorNickname || '관리자'`, `briefing.topRecipe.authorTag`로 대체.

2. **레시피 목록 ↔ 상세 화면 이동 시 미세 깜빡임(Flickering) 해결 (이슈 2)**:
   - **원인 1 (상세 화면 레이아웃 점프)**: `RecipeDetailPage.tsx`에서 `isRecipeLoading` 상태일 때 높이 200px 수준의 단일 스피너 박스를 띄우다 실제 상세 컨텐츠로 교체되면서 화면 전체가 번쩍이며 깜빡이는 현상 발생.
     - **해결**: `Skeleton.tsx`에 `RecipeDetailSkeleton` 컴포넌트를 신설하여 히어로 썸네일, 타이틀, 인분 계산기, 식재료 카드, 조리 스텝 영역과 동일한 골격의 스켈레톤을 렌더링하도록 개선.
   - **원인 2 (캐시 만료 및 재패칭)**: `useRecipe.ts`에서 `useRecipes`의 `staleTime`이 1분, `useRecipeDetail`이 2분으로 짧게 잡혀있고 `placeholderData`가 없어 화면 전환이나 뒤로가기 시 매번 로딩 상태가 유발됨.
     - **해결**: `useRecipes`에 `placeholderData: (previousData) => previousData` 및 `staleTime: 5분` 적용, `useRecipeDetail`의 `staleTime: 5분` 적용.
   - **원인 3 (라우터 searchParams 불필요 갱신)**: `RecipeFeedPage.tsx`에서 상세에서 뒤로가기 시 150ms 후 URL 파라미터가 동일함에도 무조건 `setSearchParams`가 호출되어 라우터가 재렌더링되며 깜빡임 발생.
     - **해결**: `if (prev.toString() === next.toString()) return prev;` 방어 로직 추가로 불필요한 라우터 히스토리 교체 차단.
     - `RecipeFeedPage.tsx`의 추천 모드 매핑 시 임의의 닉네임 `'뚝딱'`, 태그 `'추천'`을 `'관리자'`, `undefined`로 정규화.
