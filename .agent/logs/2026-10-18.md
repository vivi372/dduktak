### 1. 작업 내용 (Task Details)

#### 1) AOP 기반 메서드 실행 계측 및 Trace ID 추적 (`LoggingAspect.java`) 구현
- **위치**: `backend/src/main/java/com/dduktak/global/aspect/LoggingAspect.java`
- **핵심 기능**:
  - **6자리 무작위 Trace ID 발급**: HTTP 요청 또는 독립 서비스 실행 진입 시 MDC에 `traceId`가 없으면 6자리 무작위 영숫자(예: `C4E8A1`, `BCCAA5`)를 생성하여 등록
  - **계층 간 전파 및 수명주기 보장**: Controller ➔ Service 하위 계층 호출 시 기존 Trace ID를 그대로 유지하며, 최초 진입점(isRoot == true)에서만 `finally` 블록을 통해 `MDC.clear()`를 호출하여 스레드 재사용 시 메모리 누수 및 오염 방지
  - **메서드 실행 계측**: Controller/Service 메서드 진입 시 `--> [START] [{LAYER}] {Class}.{Method}({Args})`, 정상 이탈 시 `<-- [END] [{LAYER}] {Class}.{Method}() - {Time}ms | Return: {Result}`, 예외 발생 시 `<-- [ERROR] [{LAYER}] {Class}.{Method}() - {Time}ms | Exception: {Type} - {Message}` 자동 로깅
  - **레이어 자동 식별**: `@RestController`, `@Controller`, `@Service` 및 클래스명 접미사를 기반으로 `[CONTROLLER]`, `[SERVICE]` 태그 부여

#### 2) 민감 정보 평문 노출 방지(Masking) 처리 구현
- **파라미터명 기반 마스킹**: 메서드 파라미터명에 `password`, `pwd`, `token`, `secret`, `credential`, `auth` 등의 키워드가 포함될 경우 값을 일괄 `****`로 치환
- **DTO 및 문자열 패턴 마스킹**: DTO의 `toString()`이나 반환값 문자열 내부의 `password=xxx`, `token=yyy` 등의 패턴을 정규표현식(`SENSITIVE_STRING_PATTERN`)으로 탐색하여 `password=****`로 치환
- **JWT 토큰 패턴 마스킹**: `Bearer eyJ...` 또는 `eyJ...` 형태의 JWT 토큰 문자열이 단독으로 전달되거나 반환될 경우 `[PROTECTED_TOKEN]`으로 마스킹
- **웹 인프라 객체 안전 요약**: `HttpServletRequest`, `HttpServletResponse`, `HttpSession`, `MultipartFile`, `BindingResult` 등 직렬화 시 순환 참조 또는 대용량 바이너리 덤프가 일어날 수 있는 객체를 `[HttpServletRequest]`, `[MultipartFile: image.png, 1024 bytes]` 등의 요약 문자열로 안전하게 변환

#### 3) 콘솔 로그 포맷 연동 (`application.yml`)
- **위치**: `backend/src/main/resources/application.yml`
- **설정 내용**: `logging.pattern.console`에 `%clr([%X{traceId:-SYSTEM}]){magenta}`를 추가하여, AOP 로깅뿐만 아니라 도메인 내부 로그, SQL 쿼리 로그(`log4jdbc`), 전역 예외 로그(`GlobalExceptionHandler`) 전체에서 동일한 Trace ID가 마젠타 색상으로 직관적으로 표시되도록 구성
