### 📷 [증적 01] Step 3A-1: PC 2-Column Split 레이아웃 (`1024px+` `max-w-5xl` 좌 40% / 우 60%)
```text
+-----------------------------------------------------------------------------------+
|  [DesktopSidePanel (Sticky 좌 40%)]    |  [Main Content Container (우 60%)]       |
|  - 브랜드 헤더 카드 & 야간모드 토글    |  - 상단 헤더: [메뉴명] & [알림 벨]       |
|  - 유저 미니 환영 배너                 |  - 메인 피드 콘텐츠                      |
|  - 내 냉장고 실시간 브리핑             |  - 둥근 상단 모서리 (lg:rounded-t-3xl)   |
|  - 퀵 네비게이션 & 빠른 재료 등록 CTA  |                                          |
+-----------------------------------------------------------------------------------+
```
* **🔍 시각 검수 포인트**: 21:9 대형 모니터 및 1024px+ 데스크톱에서 좌측 40% Sticky 사이드 위젯 + 우측 60% 메인 피드가 모서리 라운딩과 함께 수평 밸런스를 완벽하게 유지함을 확인.

|  - 양념류 배지: [양념류 ⚪] 상시 보유 인정 및 차감 대상 자동 제외                 |

### 📷 [증적 07] Step 3A-4: [이 레시피로 요리하기] 2-Step FIFO 차감 검수 모달 & 양념류 차감 제외
```text
+-----------------------------------------------------------------------------------+
|  [Step 1: 2-Way 분기]                                                             |
|  - [재료 자동으로 차감하고 요리하기] vs [차감 없이 요리 완료 기록만 하기]         |
|  [Step 2: 냉장고 재료 차감 검수]                                                  |
|  - 임박한 재료부터 자동 FIFO 차감 리스트 브리핑                                   |
|  - 양념/소스 카테고리: [양념 - 수량차감 제외] 배지 표시 및 차감 수량 0 고정       |
|  - 연필 아이콘 안내: "수량을 터치하여 직접 변경할 수 있어요" 미세 조절 지원        |
+-----------------------------------------------------------------------------------+
```
* **🔍 시각 검수 포인트**: 2단계 확인 모달을 통해 비즈니스 정책(양념류 자동 제외, No-Mixing FIFO 차감)이 시각적으로 명확하게 안내되고 수동 수정이 지원됨을 확인.
