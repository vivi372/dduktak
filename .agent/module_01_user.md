### 📄 [모듈 1 통합 명세서] 회원, 프로필 및 마이페이지 (User, Auth & MyPage)
#### 1. 개요
*   **목적** : 유저 인증(가입/로그인), 개인 프로필 및 계정 정보(이메일, 비밀번호) 관리, 마이페이지를 통한 개인화 데이터(스크랩북, 작성 글, 알림 설정) 관리, 회원 탈퇴 시 데이터 익명화 생명주기 처리.
*   **주요 인프라** : Supabase Auth (OAuth 2.0 / JWT / Email Service), PostgreSQL, Supabase Storage.

--------------------------------------------------------------------------------

#### 2. 세부 기능 요구사항 (Functional Requirements)
##### 2.1. 이메일 회원가입 및 로그인 (AUTH-01)
*   **AUTH-01-1 [이메일 회원가입]** :
*  입력 항목: 이메일(아이디), 비밀번호 (8자 이상, 영문/숫자/특수문자 조합), 닉네임.
*  가입 시 이메일 인증 링크 발송 ➔ 클릭 승인 전까지 계정 상태는 UNVERIFIED로 유지.
*   **AUTH-01-2 [이메일 로그인 & 비밀번호 재설정]** :
*  이메일/비밀번호 검증 후 JWT 토큰(Access/Refresh) 발급.
*  로그인 불가 시 '비밀번호 재설정' 링크를 가입 이메일로 발송.
##### 2.2. 소셜 간편 로그인 (AUTH-02)
*   **AUTH-02-1 [소셜 연동]** : Kakao 및 Google OAuth 2.0 소셜 로그인 제공.
*   **AUTH-02-2 [자동 가입 및 프로필 수집]** : 최초 로그인 시 기본 프로필(이메일, 닉네임, 프로필 이미지 URL) 수집 후 이메일 인증 절차 없이 즉시 가입.
##### 2.3. 프로필 및 닉네임 정책 (USER-01)
*   **USER-01-1 [닉네임 중복 허용 및 고유 유저 태그]** :
*  닉네임 중복 가능 (예: 여러 명의  *뚝딱셰프*  존재 가능).
*  회원 가입 시 시스템이 4자리 무작위 숫자의 유저 태그(User Tag)를 자동 부여 (예: 뚝딱셰프#1024).
*   **USER-01-2 [유저 구별 및 UI 노출]** :
*  프로필 및 레시피 작성자 정보에 닉네임(#유저태그) 형태로 노출하여 식별성 보장.
*   **USER-01-3 [프로필 수정]** :
*  마이페이지 내에서 닉네임 변경 가능 (2~10자 이내, 유저 태그는 유지).
*  프로필 이미지 변경: 소셜 기본 이미지 사용 또는 Supabase Storage를 통한 지정 이미지 업로드.

--------------------------------------------------------------------------------

##### 2.4. 마이페이지 개인화 및 계정 정보 관리 (USER-PAGE)
*   **USER-PAGE-01 [계정 정보 변경 (이메일 & 비밀번호)]** :
*   **아이디(이메일) 변경 (USER-PAGE-01-1)** :
*   **이메일 로그인 유저** : 변경할 새로운 이메일 입력 ➔ 신규 이메일로 인증 확인 링크 발송 ➔ 링크 클릭 확인 완료 시 아이디(이메일) 최종 변경 완료.
*   **소셜 로그인 유저** : 연동된 소셜 계정의 고유 이메일을 사용하므로 이메일 직접 변경 불가 ( *"소셜 로그인은 해당 플랫폼에서 이메일을 변경해 주세요"*  안내 노출).
USER-PAGE-01-2 [비밀번호 재설정 (이메일 로그인 유저 전용)]:
마이페이지 내 [비밀번호 재설정] 버튼 클릭.
가입된 이메일 주소로 비밀번호 재설정 링크(Reset Link) 즉시 발송.
이메일 내 링크를 통해 이동한 보안 페이지에서 새 비밀번호 입력 및 변경 완료.
(소셜 로그인 유저인 경우 메뉴 비활성화 및 안내 문구 노출)
*   **USER-PAGE-02 [내가 작성한 레시피 관리]** :
*  본인이 작성한 레시피 목록 모아보기 (최신순).
*  작성 레시피의 요리완료 수, 좋아요 수, 조회수 현황 한눈에 확인.
*  목록에서 해당 레시피 클릭 시 상세 페이지 이동, 수정/삭제 숏컷 제공.
*   **USER-PAGE-03 [스크랩북 (북마크한 레시피)]** :
*  내가 [북마크(Saved)]한 타인의 레시피 목록 모아보기.
*  스크랩 해제(토글) 기능 제공.
*   **USER-PAGE-04 [알림 및 앱 환경설정]** :
*   **알림 수신 토글** : 소비기한 임박 알림 ON/OFF, 소셜 반응 알림 ON/OFF.
*   **야간 푸시 제한 상태 안내** :  *"야간 푸시 방지 정책에 따라 21:00 ~ 08:00에는 푸시 알림이 발송되지 않습니다."*  문구 상시 안내.
*   **USER-PAGE-05 [계정 관리 및 로그아웃]** :
*  로그아웃: 클라이언트 세션/토큰 파기 및 로그인 화면으로 이동.
*  약관 확인: 서비스 이용약관 및 개인정보 처리방침 조회.

--------------------------------------------------------------------------------

##### 2.5. 회원 탈퇴 및 데이터 처리 정책 (USER-02)
*   **USER-02-1 [약관 동의 및 안내]** :
*  필수 명시 사항:  *"회원 탈퇴 시 작성하신 레시피는 커뮤니티 생태계 보존을 위해 삭제되지 않고 익명으로 전환되어 보존됩니다."*
*   **USER-02-2 [탈퇴 시 데이터 생명주기 관리]** :
*   **즉시 완전 삭제 (Cascade Delete)** : 유저 개인 데이터(내 냉장고 재료, 알림 센터 목록, 알림 설정, 스크랩북/좋아요 내역).
*   **익명 보존 (Anonymization)** : 작성한 레시피 레코드는 삭제하지 않고 작성자 ID 연결을 해제(user_id = NULL)하여 익명 계정으로 소유권 자동 전환.
##### 2.6. 서비스 인프라 및 범위 제약 (SYS-01)
*   **SYS-01-1 [1인 1냉장고 고정]** : 공유 냉장고 미지원. 1개 계정당 1개의 독립된 내 냉장고 데이터베이스만 매핑.
