### UI/UX 가이드라인 및 에이전트 디자인 재량 명세서
#### 1. 개요
본 문서는 '오늘의 뚝딱' 프론트엔드 개발 시 AI 코딩 에이전트가 참고할 디자인 시스템 및 한국형 사용자 편의성(UX) 규칙을 정의한다. AI 에이전트는 기획된 비즈니스 요구사항을 충족하는 선에서 최상의 시각적 완성도와 유연한 디자인 재량을 발휘하여 구현한다.

--------------------------------------------------------------------------------

#### 2. 디자인 시스템 및 테마 재량 (Design Freedom)
##### 2.1. 컬러 팔레트 & 테마 설정
*   **파스텔톤 & 트렌디한 톤앤매너** : 서비스의 밝고 건강한 느낌을 살리되, 감각적인 포인트 컬러와 파스텔 계열을 조화롭게 활용한다.
*   **다크 모드 지원** : 기본 라이트 모드 외에 다크 모드를 적극 지원하며, 테마 전환 시 가독성과 눈이 편안한 색상 대비를 확보한다.
##### 2.2. UI 라이브러리 커스텀 & 스타일링
*   **Shadcn UI 커스텀 허용** : 기본 컴포넌트를 바탕으로 애니메이션(Framer Motion 등), 호버 효과, 보더/쉐도우 등을 자유롭게 커스텀하여 시각적 완성도를 높인다.
*   **Icon Set** : lucide-react를 활용하여 직관적인 아이콘을 통일감 있게 배치한다.

--------------------------------------------------------------------------------

#### 3. 화면 구조 및 반응형 레이아웃 규칙
##### 3.1. 화면 구조 및 반응형 (Responsive Layout)
*  모바일 웹뷰 환경뿐만 아니라 **PC 화면에서도 자연스럽고 유연하게 동작하는 반응형 웹(Responsive Web)**으로 설계한다.
*  큰 화면(PC)에서는 넓은 레이아웃을 효율적으로 활용하고, 모바일 화면에서는 앱과 같은 직관적인 사용성을 제공하도록 에이전트의 재량에 맡긴다.

--------------------------------------------------------------------------------

#### 4. 한국형 사용자 편의성 및 UX 규칙 (User Experience Guidelines)
##### 4.1. 직관적인 한글화 및 톤앤매너
*   **영문 UI 용어 전면 한글화** :
    *  Cancel, Confirm, Delete, Edit ➔  **[취소]** ,  **[확인]** ,  **[삭제]** ,  **[수정]**
    *  Storage, D-Day ➔  **[보관 장소]** ,  **[소비기한 N일 남음]**
*   **친근하고 명확한 해요체 활용** :
    *  (X) "재료가 성공적으로 입력되었습니다." ➔ (O)  **"계란을 냉장고에 넣었어요! 🥚"**
    *  (X) "요리가 완료되었습니다." ➔ (O)  **"맛있는 요리가 완성되었어요! 재료를 자동으로 차감했어요."**
##### 4.2. 모바일 퍼스트 & 터치 인터랙션 편의성
*   **엄지손가락 영역 (Thumb Zone) 최적화** : 1인 가구가 이동 중 한 손으로 쉽게 다루도록 핵심 액션 버튼(재료 추가, 요리 완료)은 화면 하단 영역에 우선 배치.
*   **터치 영역 최소 44px 이상 확보** : 수량 조절 버튼(+, -) 등은 손가락 오타 방지를 위해 충분한 터치 타겟 확보.
*   **모바일 폼 입력 편의성** : 수량 및 소비기한 입력 시 모바일 키보드가 자동으로 숫자 패드(inputmode="numeric")로 전환되도록 설정 및 Auto-Scroll 적용.
##### 4.3. 시각적 직관성 및 에러 처리 UX
*   **스마트한 기본값 (Default) 제공** : 식재료 카테고리 선택 시 권장 소비기한 날짜가 자동으로 세팅되어 1초 만에 등록 가능.
*   **D-Day 신호등 색상 구분** :
    *   **D-3 이내** : 빨강 (임박)
    *   **D-7 이내** : 주황 (주의)
    *   **D-7 초과** : 파랑·초록 (안심)
    *   **기한 초과** : Deep Red (소비기한 N일 지남)
*   **백엔드 에러 태그별 팝업 노출 매핑** :
    *  _FIELD_ ➔ Form 하단 빨간 텍스트
    *  _INFO_ / _WARN_ / _ERROR_ ➔ Sonner Toast
    *  _ALERT_ / _CONFIRM_ ➔ Shadcn AlertDialog 모달
*   **빈 상태 (Empty State) & Skeleton Loading** : 데이터가 없을 때는 친절한 안내 문구/일러스트를 배치하고, 로딩 시에는 Spinner 대신 Skeleton UI 적용.
