### UI/UX 가이드라인 및 에이전트 디자인 재량 명세서
#### 1. 개요
본 문서는 '오늘의 뚝딱' 프론트엔드 개발 시 AI 코딩 에이전트가 참고할 디자인 시스템 및 한국형 사용자 편의성(UX) 규칙을 정의한다. AI 에이전트는 기획된 비즈니스 요구사항을 충족하는 선에서 최상의 시각적 완성도와 유연한 디자인 재량을 발휘하여 구현한다.

--------------------------------------------------------------------------------

#### 2. 디자인 시스템 및 테마 재량 (Design Freedom)
##### 2.1. 컬러 팔레트 & 테마 설정
*   **파스텔톤 & 트렌디한 톤앤매너** : 서비스의 밝고 건강한 느낌을 살리되, 감각적인 포인트 컬러와 파스텔 계열을 조화롭게 활용한다.
*   **다크 모드 지원** : 기본 라이트 모드 외에 다크 모드를 적극 지원하며, 테마 전환 시 가독성과 눈이 편안한 색상 대비를 확보한다.
##### 2.2. UI 라이브러리 커스텀 & 스타일링
*   **Shadcn UI 커스텀 허용** : 기본 컴포넌트를 바탕으로 애니메이션(Framer Motion 등), 호버 효과, 보더/쉐도우 등을 자유롭게 커스텀하여 시각적 완성도를 높인다.
*   **Icon Set** : lucide-react를 활용하여 직관적인 아이콘을 통일감 있게 배치한다.

--------------------------------------------------------------------------------

#### 3. 화면 구조 및 반응형 레이아웃 규칙
##### 3.1. 화면 구조 및 반응형 (Responsive Layout)
*  본 프로젝트는 **Capacitor 기반 하이브리드 앱 (React 통합형)** 환경 및 모바일 웹뷰, **PC 화면에서도 자연스럽고 유연하게 동작하는 반응형 웹(Responsive Web)**으로 구현한다.
*  큰 화면(PC)에서는 넓은 레이아웃을 효율적으로 활용하고, 모바일 화면에서는 앱과 같은 직관적인 사용성을 제공하도록 에이전트의 재량에 맡긴다.

--------------------------------------------------------------------------------

#### 4. 한국형 사용자 편의성 및 UX 규칙 (User Experience Guidelines)
##### 4.1. 직관적인 한글화 및 톤앤매너
*   **영문 UI 용어 전면 한글화** :
    *  Cancel, Confirm, Delete, Edit ➔  **[취소]** ,  **[확인]** ,  **[삭제]** ,  **[수정]**
    *  Storage, D-Day ➔  **[보관 장소]** ,  **[소비기한 N일 남음]**
*   **친근하고 명확한 해요체 활용** :
    *  (X) "재료가 성공적으로 입력되었습니다." ➔ (O)  **"계란을 냉장고에 넣었어요! 🥚"**
    *  (X) "요리가 완료되었습니다." ➔ (O)  **"맛있는 요리가 완성되었어요! 재료를 자동으로 차감했어요."**
##### 4.2. 모바일 퍼스트 & 터치 인터랙션 편의성
*   **엄지손가락 영역 (Thumb Zone) 최적화** : 1인 가구가 이동 중 한 손으로 쉽게 다루도록 핵심 액션 버튼(재료 추가, 요리 완료)은 화면 하단 영역에 우선 배치.
*   **터치 영역 최소 44px 이상 확보** : 수량 조절 버튼(+, -) 등은 손가락 오타 방지를 위해 충분한 터치 타겟 확보.
*   **모바일 폼 입력 편의성** : 수량 및 소비기한 입력 시 모바일 키보드가 자동으로 숫자 패드(inputmode="numeric")로 전환되도록 설정 및 Auto-Scroll 적용.
##### 4.3. 이미지 업로드 & 클라이언트 압축 UX
*   **업로드 전 클라이언트 리사이징/압축** : 모바일 사용자가 원본 고화질 사진(10MB+)을 업로드할 때 네트워크 지연이나 업로드 실패가 발생하지 않도록, `browser-image-compression` 및 Canvas API를 통해 클라이언트 단에서 1MB 이하(1080px 기준)로 리사이징 후 업로드 진행.
*   **업로드 인디케이터 & 스켈레톤** : 이미지 업로드 중에는 로딩 인디케이터나 프로그레스 바를 표시하고, 썸네일 영역에는 Skeleton UI를 적용하여 매끄러운 UX 제공.
##### 4.4. 시각적 직관성 및 에러 처리 UX
*   **스마트한 기본값 (Default) 제공** : 식재료 카테고리 선택 시 권장 소비기한 날짜가 자동으로 세팅되어 1초 만에 등록 가능.
*   **D-Day 신호등 색상 구분** :
    *   **D-3 이내** : 빨강 (임박)
    *   **D-7 이내** : 주황 (주의)
    *   **D-7 초과** : 파랑·초록 (안심)
    *   **기한 초과** : Deep Red (소비기한 N일 지남)
*   **백엔드 에러 태그별 팝업 노출 매핑** :
    *  _FIELD_ ➔ Form 하단 빨간 텍스트
    *  _INFO_ / _WARN_ / _ERROR_ ➔ Sonner Toast
    *  _ALERT_ / _CONFIRM_ ➔ Shadcn AlertDialog 모달
*   **빈 상태 (Empty State) & Skeleton Loading** : 데이터가 없을 때는 친절한 안내 문구/일러스트를 배치하고, 로딩 시에는 Spinner 대신 Skeleton UI 적용.
##### 4.5. 회원가입 및 프로필 이미지 온보딩 UX
*   **회원가입 폼 안내 툴팁 UX** : 회원가입 화면에서는 '오늘의 뚝딱' 기본 캐릭터 아바타를 노출하고, 하단에 친절한 안내 문구를 제공하여 사용자의 질문/궁금증을 사전 해소한다.
    *  💬 *"기본 캐릭터로 먼저 시작돼요! 이메일 인증 완료 후 마이페이지에서 언제든 나만의 사진으로 변경할 수 있어요."*
*   **이메일 인증 승인 직후 온보딩 UX** : 유저가 메일함에서 인증 승인 링크를 클릭하고 첫 서비스 진입/로그인 시, 웰컴 팝업 모달을 통해 자연스러운 프로필 사진 업로드(`PATCH /me`) 경험을 제공한다.
    *  💬 *"반가워요, OOO님! 나만의 프로필 사진으로 꾸며볼까요? [프로필 설정하기] / [나중에 하기]"*

##### 4.6. 프로필 이미지 원형 미리보기 & 크롭/조절 인터랙션 UX
*   **원형 프레임 실시간 미리보기 (Circular Preview)** : 프로필 이미지는 단순 파일 첨부가 아닌, UI 상에서 1:1 정방형 원형(Circle) 아바타 프레임으로 실시간 반영되어 노출된다.
*   **인터랙티브 크롭/조절 모달 (Interactive Image Cropper)** :
    *  사진 첨부 시 즉시 원형 마스크 가이드라인이 적용된 **크롭 모달(Crop Modal / Drawer)**이 노출된다.
    *  **위치 조정 (Drag & Pan)** : 원형 마스크 내부에서 사진을 드래그하여 얼굴/원하는 부위가 중심에 오도록 위치 이동 지원.
    *  **크기 조절 (Zoom Slider)** : 모달 하단 슬라이더 바 또는 Pinch-to-zoom을 통해 사진 비율 확대/축소 지원.
    *  **클라이언트 가공 & 압축** : 사용자가 편집 완료 클릭 시 Canvas API ( 활용)로 해당 영역만 자른 뒤, 으로 1080x1080 이내/1MB 이하 압축 후 Supabase Storage로 최종 업로드.


##### 4.7. 식재료 소비 차감 & 바코드/OCR 스캔 예외 UX 가이드라인
*   **수동 소비 차감 수량 초과 방지 UX** :
    *  [소비 완료] 모달/팝업에서 소비 수량(`consumeQuantity`) 입력 시, 현재 보유 수량(`quantity`)을 초과하여 입력하지 못하도록 input의 `max` 속성 지정 및 실시간 유효성 검증을 수행한다.
    *  보유 수량보다 큰 숫자 입력 시: 제출 버튼이 비활성화되며 하단에 경고 메시지 노출 💬 *"현재 보유 수량(N개) 이하로 입력해 주세요."*
*   **바코드/OCR 스캔 실패 및 수동 전환 UX** :
    *  **바코드 미등록(404 에러)** : *"등록되지 않은 바코드 상품이에요. 수동으로 간편하게 추가해보세요!"* 안심 토스트 노출 후 수동 등록 폼으로 가이드.
    *  **영수증 OCR 인식 실패(빈 배열 `[]`)** : *"영수증 글자를 읽지 못했어요. 직접 재료를 등록해 볼까요?"* 안내 팝업과 함께 수동 입력 화면으로 매끄럽게 전환.

##### 4.7. 외부 스캔 (바코드 ML Kit & 영수증 Gemini OCR) UX
*   **앱 전용 바코드 스캔 (Google ML Kit)** : 모바일 앱 카메라인터페이스에서 Google ML Kit으로 바코드(EAN-13)를 실시간 추출하여 백엔드로 전달.
*   **바코드 매핑 실패 안내** : 푸드 QR 조회 및 `ingredient_master` 매핑 검색 실패 시 `404 Not Found`에 대해 *"등록되지 않은 바코드예요. 직접 재료를 선택해 주세요"* 팝업 노출 후 수동 등록 Combobox로 이동.
*   **영수증 OCR 스캔 (Google AI Studio Gemini Flash)** : 영수증 사진을 Google AI Studio (Gemini Flash API) 프록시로 전달하여 식재료 품목을 파싱. 파싱 실패 시 안내 문구와 함께 수동 등록 화면으로 전환.
