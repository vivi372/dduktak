     - 탈퇴 사유 선택 및 안내 모달 동의 ➔ [탈퇴하기] 최종 확정
     - 로그아웃 처리 및 로그인 화면 이동 확인
* **검증 포인트**:

### [Step 8] 네이티브 하이브리드 앱 전용 테스트 시나리오 (Capacitor Native Features)
* **목표**: 모바일 환경(Android 실기기/에뮬레이터)에서 동작하는 네이티브 고유 기능(구글 소셜 로그인, Google ML Kit 바코드 스캔, FCM 네이티브 푸시, 하드웨어 뒤로가기)의 정상 작동 여부를 **유저가 직접 수행 및 검증**하고 증적을 기록
* **실행 주체**: **사용자(Tester/User) 직접 수행** (에이전트는 시나리오 제공 및 결과 기록 가이드)
* **액션 및 시나리오 세부 항목**:

#### [Native-1] 구글 소셜 로그인 (Google OAuth & Deep Link 플로우)
1. Android 기기에서 '오늘의 뚝딱' 앱 기동
2. 로그인 화면에서 **[Google로 시작하기]** 버튼 탭
3. 시스템 브라우저 / Chrome Custom Tab으로 구글 로그인 창 호출 확인
4. 사용자의 구글 계정 선택 및 서비스 접근 권한 승인
5. 앱 전용 스키마/딥링크(`io.ionic.starter://` 또는 설정된 앱 링크)를 통해 웹뷰로 안전하게 리다이렉트 복귀 확인
6. 백엔드 `POST /api/v1/auth/init` 호출 및 세션 획득 ➔ 메인 홈 화면으로 정상 진입 확인
7. 하단 [마이] 탭 이동 시, 계정 정보 영역에 "구글 연동 계정" 배지가 표시되고 이메일/비밀번호 변경 버튼이 안전하게 숨겨져 있는지 확인

#### [Native-2] Google ML Kit 카메라 바코드 스캔을 통한 식재료 즉시 등록
1. 하단 [냉장고] 탭 이동
2. 네이티브 환경에서만 노출되는 **[바코드 스캔]** CTA 버튼 노출 확인 (웹에서는 미노출)
3. [바코드 스캔] 버튼 탭 ➔ 네이티브 카메라 권한 요청 팝업 시 [허용] 탭
4. Google Barcode Scanner Activity(카메라 뷰파인더 화면) 실행 확인
5. 실제 가공식품(예: 신라면, 햇반, 참치캔 등 `880...` EAN-13 표준 바코드)을 카메라에 위치
6. 바코드 인식 즉시 햅틱 진동 피드백과 함께 뷰파인더가 닫히며 앱으로 복귀
7. 백엔드 `GET /api/v1/inventory/barcode/{barcodeNo}` 호출을 통해 조회된 식재료명("신라면"), 표준 카테고리("면/라면류"), 권장 보관방식("실온")이 자동 입력된 [식재료 등록 모달] 오픈 확인
8. 수량(예: 1개)과 소비기한 확인 후 [등록 완료] 탭 ➔ 냉장고 목록에 즉시 반영되는지 확인
9. **[미등록 바코드 엣지케이스]**: 등록되지 않은 임의의 바코드 스캔 시 크래시 없이 *"등록되지 않은 바코드입니다. 직접 이름을 입력해 주세요."* 안내 토스트가 뜨고 수동 등록 폼으로 부드럽게 전이되는지 확인

#### [Native-3] FCM(Firebase Cloud Messaging) 네이티브 푸시 알림 수신
1. 앱 최초 기동 또는 마이페이지에서 알림 권한 팝업 시 [허용] 탭
2. 앱을 백그라운드로 전환 (홈 버튼 탭)
3. 서버/스케줄러 또는 상호작용 트리거(유저 B의 좋아요 또는 소비기한 D-1 임박 알림) 발생
4. Android 상단 상태표시줄(Status Bar)에 '오늘의 뚝딱' 로고 아이콘과 함께 푸시 알림 도착 확인
5. 수신된 푸시 알림 알림창 탭 ➔ 앱이 포그라운드로 복귀하며 해당 알림 상세 화면(알림함 또는 레시피 상세)으로 딥링크 자동 이동 확인

#### [Native-4] 하드웨어 뒤로가기(Physical Back Button) 및 오버레이 방어
1. 레시피 등록 폼 또는 식재료 등록 모달이 열려 있는 상태에서 Android 기기 하단 물리/제스처 뒤로가기 버튼 입력
2. 앱 전체가 즉시 종료되지 않고, 열려 있던 모달/바텀시트만 안전하게 닫히는지 확인
3. 홈 화면 최상단에서 뒤로가기 입력 시 *"한 번 더 누르면 앱이 종료됩니다"* 토스트 노출 후 재입력 시 정상 종료되는지 확인

* **검증 포인트**:
  - [ ] 구글 소셜 로그인 ➔ 시스템 브라우저 인증 ➔ 앱 딥링크 복귀 ➔ 메인 진입 100% 정상
  - [ ] 소셜 유저 마이페이지에서 계정 정보 분기(비밀번호/이메일 변경 숨김) 정상
  - [ ] Google ML Kit 카메라 바코드 스캐너 구동 및 EAN-13 실시간 인식 정상
  - [ ] 바코드 인식 후 백엔드 API 연동을 통한 식재료 정보 자동 매핑 및 등록 정상
  - [ ] 미등록 바코드 스캔 시 수동 입력 폼 친절한 전이
  - [ ] 백그라운드 상태에서 FCM 네이티브 푸시 노티피케이션 수신 및 터치 시 딥링크 이동 정상
  - [ ] 안드로이드 하드웨어 뒤로가기 키 입력 시 모달 닫힘 우선 처리 및 앱 급종료 방어
