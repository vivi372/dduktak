### [Step 5] 3-Way 요리 완료 실행 ➔ 냉장고 선입선출(FIFO) 차감 정밀 검증 (Cooking)
* **목표**: 3가지 요리 완료 모드(차감 없음 / 인분 조절 차감 / 기본 정량 차감)별 냉장고 FIFO 차감 정합성 검증
* **액션**:
  1. **[1차 실행: 차감 없이 요리 완료]**:
     - 레시피 상세 하단 [뚝딱 요리완료] 클릭 ➔ 요리 완료 모달에서 [냉장고 재료 자동 차감] 체크 해제 ➔ [완료하기] 클릭
     - 검증: 냉장고 재료 수량 전혀 차감되지 않음 확인, 레시피 `cooked_count` 1 증가 확인
  2. **[2차 실행: 인분 조절(또는 모달 수량 조절) 후 차감 완료]**:
     - 레시피 상세에서 2인분으로 변경(또는 요리완료 모달에서 돼지고기 차감 수량을 300g으로 수동 변경) ➔ [완료하기] 클릭
     - 검증: 소비기한 빠른 D-1 돼지고기에서 300g 정확히 차감 확인
  3. **[3차 실행: 기본 레시피 정량 차감 완료 (FIFO 다중 레코드 관통 검증)]**:
     - 기본 1인분(돼지고기 200g, 김치 150g) 상태로 [완료하기] 클릭
     - 검증: D-1 돼지고기 잔여량이 부족할 경우 나머지 수량이 D-15 돼지고기에서 순차 차감되는지 확인
* **검증 포인트**:
  - [ ] `POST /api/v1/matching/cook/{recipeId}` 3회 각각 200 OK (`X-Trace-Id` 확보)
  - [ ] **DB 정밀 검증 (FIFO)**:
    - 1차: `user_ingredient` 수량 불변, `recipe.cooked_count` = 1
    - 2차: D-1 돼지고기 600g 중 300g 차감 ➔ 잔여 300g, `recipe.cooked_count` = 2
    - 3차: D-1 돼지고기 잔여 300g 중 200g 추가 차감 ➔ 잔여 100g, D-15 돼지고기 800g 유지, 김치 150g 차감, `recipe.cooked_count` = 3
