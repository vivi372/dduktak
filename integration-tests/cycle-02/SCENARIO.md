  2. 3-Way 요리 완료 모달 오픈:
     - [차감 없이 완료]: 요리 완료 카운트만 +1 증가하고 냉장고 재료는 보존.

     - [기본 FIFO 차감 후 완료]: 소비기한이 가장 임박한 재료부터 선입선출(FIFO)로 자동 차감.
  3. FIFO 자동 차감 실행 ➔ 내 냉장고로 이동하여 소비기한이 가장 빠른 재료부터 수량이 올바르게 줄어들었는지 검증.
